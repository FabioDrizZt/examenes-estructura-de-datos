1. Memoria y Structs Anidados

Ponderación: 15% (a: 7.5% | b: 7.5%)

El centro de control de una agencia aeroespacial monitorea constelaciones de satélites de órbita baja (LEO). Dadas las siguientes declaraciones de tipos estructurados en C:

// Definición Struct Base 
struct stCoordenadaOrbital {
    float ApogeoKm;             // 4 bytes
    float PerigeoKm;            // 4 bytes
    float InclinacionGrados;    // 4 bytes
    float VelocidadOrbitalKms;  // 4 bytes
    unsigned shortint OrbitaNro;// 2 bytes
    char EstadoPropulsion;      // 1 byte
    char IdSatelite[7];         // 7 bytes
};
// Definición Struct Compuesto 
struct stModuloSatelite {
    char CodigoMision[16];           // 16 bytes
    char AgenciaEspacial[30];        // 30 bytes
    stCoordenadaOrbital OrbitaGPS;   // anidado
    float CargaBateriaWatts;         // 4 bytes
    unsigned int TiempoMisionDias;   // 4 bytes
    char NivelRadiacion;             // 1 byte
    char NombreModuloInstrumento[49];// 49 bytes
};
Consignas a responder justificando el cálculo en bytes:
  1. a. Indique la cantidad total de bytes ocupados en memoria por la variable simple: stCoordenadaOrbital PosicionSat;
  2. b. Indique la memoria total requerida para un vector de 25 satélites: stModuloSatelite ConstelacionSat[25];
💡 Ver verificación de cálculo analítico

• stCoordenadaOrbital: 4 + 4 + 4 + 4 + 2 + 1 + 7 = 26 bytes.

• stModuloSatelite: 16 + 30 + 26 (stCoordenadaOrbital) + 4 + 4 + 1 + 49 = 130 bytes por registro.

• ConstelacionSat[25]: 130 bytes × 25 = 3250 bytes.

int misterio3(const int arr[], int n) {
    if (n == 1) {
        return (arr[0] % 2 == 0) ? arr[0] : 999999; // Caso base
    }
    int minResto = misterio3(arr, n - 1);

5. Problema Integrador en C++: Cola Dinámica + Lista Enlazada

Ponderación: 45%

Desarrolle en C++ estándar un programa modular para la codificación y ensamblado de paquetes de telemetría de vuelo utilizando estructuras de datos dinámicas con punteros.

Criterios de Carga y Algoritmo de Codificación:

  • 1. Validación de Entrada: Palabra de entre 5 y 25 caracteres, solo letras alfabéticas.
  • 2. Partición por Posición de Índice:
    • Caracteres en índice par ($0, 2, 4, \dots$) → se encolan en una COLA DINÁMICA (FIFO).
    • Caracteres en índice impar ($1, 3, 5, \dots$) → se insertan al final de una LISTA SIMPLEMENTE ENLAZADA.
  • 3. Alternancia de Mitades (Iniciando por la COLA):
    1. 1ª Mitad de la Cola (desencolando (N_cola / 2) + (N_cola % 2) elementos).
    2. 1ª Mitad de la Lista (extrayendo del frente (N_lista / 2) + (N_lista % 2) elementos).
    3. 2ª Mitad restante de la Cola (hasta vaciarla).
    4. 2ª Mitad restante de la Lista (hasta vaciarla).
  • 4. Vaciado Total: Ambas estructuras deben quedar vacías al culminar.

Ejemplo de Ejecución Demostrado:

Palabra ingresada: satelital (longitud: 9 letras)

COLA (Índices Pares: 5 letras)
frente -> [ 's' , 't' , 'l' , 't' , 'l' ] <- fin
LISTA (Índices Impares: 4 letras)
inicio -> ['a']->['e']->['i']->['a']->NULL
Secuencia de Extracción de Mitades:
1) 3 letras desencoladas de la Cola: 's', 't', 'l'
2) 2 letras del frente de la Lista: 'a', 'e'
3) 2 letras restantes de la Cola: 't', 'l'
4) 2 letras restantes de la Lista: 'i', 'a'
→ Palabra Codificada: stlaetlia

Menú Modular Requerido:

1. Ingreso y validación de palabra
2. Cargar en Cola y Lista dinámicas
3. Mostrar estructuras dinámicas
4. Codificar palabra y vaciar TDAs
0. Salir del programa

Estructura para Cola Dinámica y Lista Simplemente Enlazada.

#include <iostream>
#include <cstring>
#include <cctype>

using namespace std;

// ==========================================
// TDA COLA DINÁMICA (ÍNDICES PARES)
// ==========================================
struct NodoCola {
    char dato;
    NodoCola* sig;
};

struct Cola {
    NodoCola* frente;
    NodoCola* fin;
};

void InicializarCola(Cola &c) {
    c.frente = NULL;
    c.fin = NULL;
}

void Encolar(Cola &c, char valor) {
    NodoCola* nuevo = new NodoCola();
    nuevo->dato = valor;
    nuevo->sig = NULL;
    if (c.frente == NULL) {
        c.frente = nuevo;
    } else {
        c.fin->sig = nuevo;
    }
    c.fin = nuevo;
}

char Desencolar(Cola &c) {
    if (c.frente == NULL) return '\0';
    NodoCola* aux = c.frente;
    char valor = aux->dato;
    c.frente = c.frente->sig;
    if (c.frente == NULL) c.fin = NULL;
    delete aux;
    return valor;
}

// ==========================================
// TDA LISTA ENLAZADA SIMPLE (ÍNDICES IMPARES)
// ==========================================
struct NodoLista {
    char dato;
    NodoLista* sig;
};

void InsertarFinal(NodoLista* &inicio, char valor) {
    NodoLista* nuevo = new NodoLista();
    nuevo->dato = valor;
    nuevo->sig = NULL;
    if (inicio == NULL) {
        inicio = nuevo;
    } else {
        NodoLista* aux = inicio;
        while (aux->sig != NULL) {
            aux = aux->sig;
        }
        aux->sig = nuevo;
    }
}

char ExtraerFrente(NodoLista* &inicio) {
    if (inicio == NULL) return '\0';
    NodoLista* aux = inicio;
    char valor = aux->dato;
    inicio = inicio->sig;
    delete aux;
    return valor;
}

// Prototipos modulares
void MostrarMenu(int &opc);
