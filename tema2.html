1. Memoria y Structs Anidados

Ponderación: 15% (a: 7.5% | b: 7.5%)

El sistema de despacho eléctrico de una distribuidora energética monitorea en tiempo real los parámetros de potencia en sus centros de transformación. Dadas las siguientes declaraciones en C:

// Definición Struct Base 
struct stFaseElectrica {
    float TensionVoltios;           // 4 bytes
    float CorrienteAmperios;        // 4 bytes
    float PotenciaActivaKw;         // 4 bytes
    unsigned shortint FrecuenciaHz; // 2 bytes
    char EstadoFase;                // 1 byte ('N', 'S', 'C')
    char CodigoSensor[7];           // 7 bytes
};
// Definición Struct Compuesto 
struct stTransformador {
    char IdSubestacion[15];        // 15 bytes
    char UbicacionBarrio[35];      // 35 bytes
    stFaseElectrica FasePrimaria;  // anidado
    unsigned shortint TemperaturaC;// 2 bytes
    float CapacidadMaximaKva;      // 4 bytes
    char TipoAislacion;            // 1 byte
    char RedZonaDistribucion[39];  // 39 bytes
};
Consignas a responder justificando el cálculo en bytes:
  1. a. Indique la cantidad total de bytes ocupados en memoria por la variable: stFaseElectrica MonitoreoR;
  2. b. Indique la memoria total requerida para un arreglo estático de 30 transformadores: stTransformador ParqueTransformadores[30];
💡 Ver verificación de cálculo analítico

• stFaseElectrica: 4 + 4 + 4 + 2 + 1 + 7 = 22 bytes.

• stTransformador: 15 + 35 + 22 (stFaseElectrica) + 2 + 4 + 1 + 39 = 118 bytes por elemento.

• ParqueTransformadores[30]: 118 bytes × 30 registros = 3540 bytes.

5. Problema Integrador en C++: Lista Enlazada + Pila Dinámica

Ponderación: 45%

Desarrolle en C++ estándar un programa modular para la codificación segura de tramas de telemetría energética utilizando memoria dinámica con punteros.

Criterios de Carga y Algoritmo de Codificación:

  • 1. Validación de Entrada: Palabra de longitud entre 5 y 25 caracteres, solo letras alfabéticas sin espacios.
  • 2. Partición por Rango Alfabético:
    • Caracteres en el rango alfabético ['a' .. 'm'] → se insertan al final de una LISTA SIMPLEMENTE ENLAZADA.
    • Caracteres en el rango alfabético ['n' .. 'z'] → se apilan en una PILA DINÁMICA (LIFO).
  • 3. Alternancia de Mitades (Iniciando por la LISTA ENLAZADA):
    1. 1ª Mitad de la Lista (extrayendo del frente (N_lista / 2) + (N_lista % 2) elementos).
    2. 1ª Mitad de la Pila (desapilando (N_pila / 2) + (N_pila % 2) elementos).
    3. 2ª Mitad restante de la Lista (hasta vaciarla).
    4. 2ª Mitad restante de la Pila (hasta vaciarla).
  • 4. Vaciado: Ambas estructuras deben quedar con sus punteros cabecera en NULL tras la codificación.

Ejemplo de Ejecución Demostrado:

Palabra ingresada: redesenergeticas (longitud: 16 letras)

LISTA ['a'..'m'] (9 letras)
inicio -> [e]->[d]->[e]->[e]->[g]->[e]->[i]->[c]->[a]->NULL
PILA ['n'..'z'] (7 letras)
tope -> [ s ]
        [ t ]
        [ r ]
        [ n ]
        [ s ]
        [ r ]
fondo-> [ r ] (7 consonantes altas)
Secuencia de Extracción de Mitades:
1) 5 letras del frente de la Lista: 'e', 'd', 'e', 'e', 'g'
2) 4 letras desapiladas de la Pila: 's', 't', 'r', 'n'
3) 4 letras restantes de la Lista: 'e', 'i', 'c', 'a'
4) 3 letras restantes de la Pila: 's', 'r', 'r'
→ Palabra Codificada: edeegstrneicasrr

Menú Modular Requerido:

1. Ingreso y validación de palabra
2. Cargar en Lista y Pila dinámicas
3. Mostrar estructuras dinámicas
4. Codificar palabra y vaciar TDAs
0. Salir del programa

Estructura para Lista Simplemente Enlazada y Pila Dinámica.

#include <iostream>
#include <cstring>
#include <cctype>

using namespace std;

// ==========================================
// TDA LISTA ENLAZADA SIMPLE (['a' .. 'm'])
// ==========================================
struct NodoLista {
    char dato;
    NodoLista* sig;
};

void InsertarFinal(NodoLista* &inicio, char valor) {
    NodoLista* nuevo = new NodoLista();
    nuevo->dato = valor;
    nuevo->sig = NULL;
    if (inicio == NULL) {
        inicio = nuevo;
    } else {
        NodoLista* aux = inicio;
        while (aux->sig != NULL) {
            aux = aux->sig;
        }
        aux->sig = nuevo;
    }
}

char ExtraerFrente(NodoLista* &inicio) {
    if (inicio == NULL) return '\0';
    NodoLista* aux = inicio;
    char valor = aux->dato;
    inicio = inicio->sig;
    delete aux;
    return valor;
}

// ==========================================
// TDA PILA DINÁMICA (['n' .. 'z'])
// ==========================================
struct NodoPila {
    char dato;
    NodoPila* sig;
};

void Apilar(NodoPila* &tope, char valor) {
    NodoPila* nuevo = new NodoPila();
    nuevo->dato = valor;
    nuevo->sig = tope;
    tope = nuevo;
}

char Desapilar(NodoPila* &tope) {
    if (tope == NULL) return '\0';
    NodoPila* aux = tope;
    char valor = aux->dato;
    tope = tope->sig;
    delete aux;
    return valor;
}

// Prototipos modulares
void MostrarMenu(int &opc);
bool ValidarPalabra(const char pal[]);
void CargarEstructuras(const char pal[], NodoLista* &lista, NodoPila* &pila, int &cLista, int &cPila);
void CodificarPalabra(NodoLista* &lista, NodoPila* &pila, int cLista, int cPila, char resultado[]);

int main() {
    int opcion = -1;
    char palabra[50] = "";
    char resultado[50] = "";
    NodoLista* lista = NULL;
    NodoPila* pila = NULL;
    int cLista = 0, cPila = 0;

    do {
        MostrarMenu(opcion);
        switch(opcion) {
            case 1:
                cout << "Ingrese palabra (5 a 25 caracteres): ";
                cin >> palabra;
                break;
            case 2:
                CargarEstructuras(palabra, lista, pila, cLista, cPila);
                break;
            case 3:
                // Mostrar estado de estructuras
                break;
            case 4:
                CodificarPalabra(lista, pila, cLista, cPila, resultado);
                cout << "Codificada: " << resultado << endl;
                break;
            case 0:
                cout << "Fin del programa." << endl;
                break;
        }
    } while (opcion != 0);

    return 0;
}
