1. Memoria y Structs Anidados

Ponderación: 15% (a: 7.5% | b: 7.5%)

Un controlador de celda robotizada administra brazos articulados de 6 grados de libertad en una planta de ensamblaje automatizado. Dadas las siguientes declaraciones en lenguaje C:

// Definición Struct Base 
struct stArticulacionRobot {
    float AnguloRadianes;       // 4 bytes
    float VelocidadAngular;     // 4 bytes
    float TorqueMotorNm;        // 4 bytes
    unsigned shortint CargaCorrienteMa; // 2 bytes
    char EstadoFreno;           // 1 byte ('A', 'L')
    char EjeId[3];              // 3 bytes
};
// Definición Struct Compuesto 
struct stBrazoIndustrial {
    char NumeroSerieCelda[18];      // 18 bytes
    char FabricanteRobot[26];       // 26 bytes
    stArticulacionRobot EjeMuneca;  // anidado
    unsigned int CiclosCompletados; // 4 bytes
    float HorasOperacion;           // 4 bytes
    char ModoOperacion;             // 1 byte
    char ModeloControlador[33];     // 33 bytes
};
Consignas a responder justificando el cálculo en bytes:
  1. a. Indique la cantidad total de bytes ocupados en memoria por la variable simple: stArticulacionRobot EjeCentral;
  2. b. Indique la memoria total requerida para un arreglo estático de 35 robots: stBrazoIndustrial LineaMontaje[35];
💡 Ver verificación de cálculo analítico

• stArticulacionRobot: 4 + 4 + 4 + 2 + 1 + 3 = 18 bytes.

• stBrazoIndustrial: 18 + 26 + 18 (stArticulacionRobot) + 4 + 4 + 1 + 33 = 104 bytes por elemento.

• LineaMontaje[35]: 104 bytes × 35 registros = 3640 bytes.

4. Análisis Recursivo Incógnito (Productorio de Positivos)

long long misterio4(const int arr[], int n) {
    if (n == 0) {
        return 1; // Caso base multiplicativo
    }
    long long prodParcial = misterio4(arr, n - 1);
    if (arr[n - 1] > 0) {
        return prodParcial * arr[n - 1];
    } else {
        return prodParcial;

}

5. Problema Integrador en C++: Pila Dinámica + Lista Enlazada

Ponderación: 45%

Desarrolle en C++ estándar un programa modular para la codificación y empaquetamiento de instrucciones robóticas de planta empleando memoria dinámica con punteros.

Criterios de Carga y Algoritmo de Codificación:

  • 1. Validación de Entrada: Palabra de longitud entre 5 y 25 caracteres, solo letras alfabéticas sin espacios.
  • 2. Partición por Tipo de Carácter:
    • Las CONSONANTES → se apilan en una PILA DINÁMICA (LIFO).
    • Las VOCALES → se insertan al final de una LISTA SIMPLEMENTE ENLAZADA.
  • 3. Alternancia de Mitades (Iniciando por la LISTA ENLAZADA de Vocales):
    1. 1ª Mitad de la Lista (extrayendo del frente (N_vocales / 2) + (N_vocales % 2) elementos).
    2. 1ª Mitad de la Pila (desapilando (N_consonantes / 2) + (N_consonantes % 2) elementos).
    3. 2ª Mitad restante de la Lista (hasta vaciarla).
    4. 2ª Mitad restante de la Pila (hasta vaciarla).
  • 4. Vaciado: Ambas estructuras dinámicas deben quedar rigurosamente vacías al culminar el proceso.

Estructura para Lista Enlazada (vocales) y Pila Dinámica (consonantes).

#include <iostream>
#include <cstring>
#include <cctype>

using namespace std;

// ==========================================
// TDA LISTA ENLAZADA SIMPLE (VOCALES)
// ==========================================
struct NodoLista {
    char dato;
    NodoLista* sig;
};

void InsertarFinal(NodoLista* &inicio, char valor) {
    NodoLista* nuevo = new NodoLista();
    nuevo->dato = valor;
    nuevo->sig = NULL;
    if (inicio == NULL) {
        inicio = nuevo;
    } else {
        NodoLista* aux = inicio;
        while (aux->sig != NULL) {
            aux = aux->sig;
        }
        aux->sig = nuevo;
    }
}

char ExtraerFrente(NodoLista* &inicio) {
    if (inicio == NULL) return '\0';
    NodoLista* aux = inicio;
    char valor = aux->dato;
    inicio = inicio->sig;
    delete aux;
    return valor;
}

// ==========================================
// TDA PILA DINÁMICA (CONSONANTES)
// ==========================================
struct NodoPila {
    char dato;
    NodoPila* sig;
};

void Apilar(NodoPila* &tope, char valor) {
    NodoPila* nuevo = new NodoPila();
    nuevo->dato = valor;
    nuevo->sig = tope;
    tope = nuevo;
}

char Desapilar(NodoPila* &tope) {
    if (tope == NULL) return '\0';
    NodoPila* aux = tope;
    char valor = aux->dato;
    tope = tope->sig;
    delete aux;
    return valor;
}

// Prototipos modulares
bool EsVocal(char c);
void MostrarMenu(int &opc);

void CodificarPalabra(NodoLista* &lista, NodoPila* &pila, int cVocales, int cConsonantes, char res[]);
